# Font Assets

Place the following font files here and add them to the Xcode target + Info.plist:

- PressStart2P-Regular.ttf   → https://fonts.google.com/specimen/Press+Start+2P
- VT323-Regular.ttf          → https://fonts.google.com/specimen/VT323

Info.plist entry required:
  <key>UIAppFonts</key>
  <array>
    <string>PressStart2P-Regular.ttf</string>
    <string>VT323-Regular.ttf</string>
  </array>
